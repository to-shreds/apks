# APK Shelf library

Use APK Shelf on Fire TV to download APKs from this repository and its [published Releases](https://github.com/to-shreds/apks/releases).

- **Smaller APKs:** Upload `.apk` files to this repository's root with **Add file → Upload files** (GitHub's browser limit is 25 MiB).
- **Larger APKs:** Attach the `.apk` to the published **Apk library** Release (up to 2 GiB per asset).
- On Fire TV, select **Refresh** in APK Shelf to see newly uploaded files.

**Latest APK Shelf: [1.0.4](APK-Shelf-1.0.4.apk)**. You can select it in your currently installed APK Shelf and confirm the Android update, without uninstalling the app. [Direct APK download](https://raw.githubusercontent.com/to-shreds/apks/main/APK-Shelf-1.0.4.apk).

Version 1.0.4 adds **Installed apps**, a local list of system and user applications with search, filters, favorites, app info, user-app uninstall through Android's confirmation screen, and a **Hide in Shelf only** option. It also displays reversible ADB disable/enable commands for system apps, but does **not** execute those commands or remove apps from Amazon's home screen. More details: [APK Shelf source and instructions](https://github.com/to-shreds/torbox-web-player/tree/native-updates/native/apk-shelf).

This GitHub repository and its Release assets are public. Only upload APKs you are authorized to distribute.
